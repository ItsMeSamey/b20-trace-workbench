# Attribution and scope

The MIT license covers this project's original code, tests, documentation and authored protocol cases. The implementation and cases were developed with AI assistance and separately reviewed. The expected cases were frozen before their author inspected the implementation.

Protocol semantics and event signatures were taken from Base's public B20 documentation, linked in `PROVENANCE.json`. This package contains no copied documentation pages and is not affiliated with or endorsed by Base or Coinbase.

`fixtures/metadata/captured-page-projection.json` contains selected factual fields from one public Coinbase Tokenized Stocks API response. Descriptive prose and icon links were omitted. The projection is provided as a provenance-labelled interoperability sample; the project's MIT grant does not purport to license third-party data, names or marks. Original and projected hashes, acquisition time and removed fields are recorded in `PROVENANCE.json`. No account, wallet, key or nonpublic record is included.

Authored traces are synthetic compatibility inputs, not records of chain activity. The metadata page is real but partial and is not used as an exact state-history oracle. No RPC connectivity or financial action is required to run this package.
